# 示例：推理类 Prompt 优化

## 原始 Prompt

```
帮我分析一下这个商业决策对不对
```

## 问题诊断

| # | 问题维度 | 具体问题 |
|---|---------|---------|
| 1 | 模糊性 | 没有说明是什么商业决策 |
| 2 | 完整性 | 缺少决策背景、可选方案、评估标准 |
| 3 | 输出规范 | 没有指定分析框架和输出格式 |
| 4 | 约束缺失 | 没有给出行业、规模、时间维度等约束 |

## 优化后的 Prompt

```
# 角色
你是一位具有 15 年经验的商业战略顾问，擅长初创企业的增长策略分析。

# 任务
分析以下商业决策是否合理，并给出你的建议。

# 决策背景
- 公司：[公司名/类型]，B2B SaaS，ARR $2M，团队 20 人
- 决策：计划将 60% 的工程资源投入开发新产品线，同时现有产品仍有大量客户需求未满足
- 目标：6 个月内推出新产品，开拓第二增长曲线
- 替代方案：继续深耕现有产品，提升 NRR

# 分析要求
请从以下维度逐一分析：

1. **战略匹配度** — 是否与公司阶段和核心能力匹配？
2. **资源可行性** — 以当前团队规模，是否能同时支撑两条线？
3. **风险评估** — 最大风险是什么？最坏情况是什么？
4. **机会成本** — 不做这个决策会损失什么？
5. **时机判断** — 现在是最佳时机吗？

# 输出格式
## 综合判断
[一句话结论：支持/反对/有条件支持]

## 逐维度分析
[每个维度 2-3 句话分析]

## 关键风险 Top 3
[列出并量化]

## 我的建议
[具体行动建议，包含里程碑和止损条件]

# 约束
- 基于给定信息分析，如果信息不足，明确指出缺少什么再继续
- 不要给模棱两可的建议，要有明确倾向
```

## 改动说明

| # | 原始问题 | 优化措施 | 应用技巧 | 预期效果 |
|---|---------|---------|---------|---------|
| 1 | 无角色设定 | 添加商业顾问角色 | Role Prompting | 提升分析专业度 |
| 2 | 缺少具体信息 | 补充决策背景和数据 | Context Setting | 让分析有的放矢 |
| 3 | 分析无框架 | 定义 5 个分析维度 | Chain of Thought | 确保全面分析不遗漏 |
| 4 | 输出不明确 | 规定结构化输出格式 | Structured Output | 输出可直接用于决策 |
| 5 | 无约束条件 | 添加明确性要求 | Constraint Setting | 避免废话和模棱两可 |

## 测试建议

1. **完整性测试** — 检查输出是否覆盖了所有 5 个分析维度
2. **明确性测试** — 检查"综合判断"是否给出了明确的支持/反对立场
3. **信息不足测试** — 故意省略部分背景，看模型是否主动指出
4. **对比测试** — 用优化前后的 prompt 各跑 3 次，比较分析深度
5. **极端测试** — 换一个明显错误的决策，看分析是否能识别出来
