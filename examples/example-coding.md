# 示例：代码类 Prompt 优化

## 原始 Prompt

```
写一个爬虫帮我爬数据
```

## 问题诊断

| # | 问题维度 | 具体问题 |
|---|---------|---------|
| 1 | 模糊性 | 爬什么网站？什么数据？ |
| 2 | 完整性 | 缺少语言、框架、存储方式等技术信息 |
| 3 | 输出规范 | 没有代码质量要求 |
| 4 | 约束缺失 | 没有反爬处理、频率控制、错误处理等要求 |
| 5 | 可测试性 | 无法判断爬取是否正确 |

## 优化后的 Prompt

```
# 角色
你是一位精通 Python 爬虫开发的高级工程师，熟悉 requests、BeautifulSoup、Scrapy 等工具。

# 任务
编写一个 Python 爬虫脚本，爬取豆瓣电影 Top250 的电影信息。

# 技术要求
- 语言：Python 3.10+
- HTTP 库：requests
- 解析库：BeautifulSoup4
- 存储：CSV 文件

# 需要爬取的字段
每部电影提取以下信息：
1. 排名
2. 电影名称（中文）
3. 导演
4. 主演（前3位）
5. 年份
6. 评分
7. 评分人数
8. 一句话短评

# 功能要求
1. 支持翻页（共 10 页，每页 25 部）
2. 请求间隔 2-5 秒随机延迟
3. 模拟浏览器 User-Agent
4. 失败自动重试 3 次
5. 支持断点续爬（记录已爬取页数）
6. 输出爬取进度

# 代码质量要求
- 使用函数封装，不要写成一坨
- 包含完整的异常处理（网络错误、解析错误）
- 添加类型注解
- 关键步骤添加日志
- 配置项（URL、延迟、重试次数）放在文件顶部作为常量

# 输出
1. 完整可运行的 Python 脚本
2. requirements.txt
3. 运行方式说明

# 示例输出格式（CSV）
排名,电影名,导演,主演,年份,评分,评分人数,短评
1,肖申克的救赎,弗兰克·德拉邦特,"蒂姆·罗宾斯,摩根·弗里曼,...",1994,9.7,2800000,希望让人自由

# 禁止事项
- 不要使用 Selenium（目标页面不需要 JS 渲染）
- 不要忽略反爬措施
- 不要在代码中硬编码绝对路径
```

## 改动说明

| # | 原始问题 | 优化措施 | 应用技巧 | 预期效果 |
|---|---------|---------|---------|---------|
| 1 | 目标不明 | 指定具体爬取目标和字段 | Specificity | 代码有明确目标 |
| 2 | 无技术约束 | 指定语言版本和库 | Constraint Setting | 避免不兼容代码 |
| 3 | 功能模糊 | 列出 6 项具体功能需求 | Task Decomposition | 功能完整不遗漏 |
| 4 | 无质量要求 | 添加代码规范和禁止事项 | Constraint Setting | 输出工程级代码 |
| 5 | 无输出示例 | 提供 CSV 格式示例 | Few-shot / Structured Output | 格式符合预期 |

## 测试建议

1. **可运行测试** — 直接运行生成的代码，检查是否能成功爬取第一页
2. **字段完整性** — 检查输出 CSV 是否包含所有 8 个字段
3. **异常处理测试** — 断网后运行，检查是否优雅处理错误
4. **延迟验证** — 确认请求间隔是否在 2-5 秒范围内
5. **断点续爬测试** — 中途终止后重新运行，是否从断点继续
