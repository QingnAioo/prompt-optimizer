# 示例：写作类 Prompt 优化

## 原始 Prompt

```
帮我写一篇公众号文章
```

## 问题诊断

| # | 问题维度 | 具体问题 |
|---|---------|---------|
| 1 | 模糊性 | 什么主题？什么公众号？ |
| 2 | 完整性 | 缺少受众、风格、长度等所有关键信息 |
| 3 | 输出规范 | 没有结构要求 |
| 4 | 约束缺失 | 无语调、用语、格式等约束 |

## 优化后的 Prompt

```
# 角色
你是一位深耕科技自媒体 5 年的内容创作者，擅长将复杂技术概念用通俗有趣的方式讲给普通人听。文风幽默但不浮夸，有料但不学究。

# 任务
撰写一篇关于"AI Agent 为什么突然火了"的微信公众号文章。

# 目标受众
- 25-35 岁互联网从业者
- 对 AI 有基本了解（知道 ChatGPT）但不是技术专家
- 碎片化阅读，注意力有限
- 期望：快速了解 AI Agent 是什么、为什么重要、跟自己有什么关系

# 内容要点（必须覆盖）
1. AI Agent 的通俗定义（用类比解释）
2. 为什么 2024-2025 年突然爆发（技术+商业原因）
3. 2-3 个具体应用场景（让读者有代入感）
4. 对普通从业者的影响和建议

# 风格要求
- 语调：轻松专业，像一个懂技术的朋友在跟你聊天
- 开头：用一个日常场景或反直觉观点 hook 住读者
- 节奏：短句为主，每段不超过 4 行，适当用表情符号
- 金句：每个小节有一句可以被截图转发的金句
- 结尾：给读者一个可执行的小行动

# 格式规范
- 总字数：1500-2000 字
- 结构：标题 + 引言 + 3-4 个小节（每节有小标题）+ 结尾
- 标题风格：引发好奇但不标题党（参考：少数派、虎嗅风格）
- 段落间用空行分隔，适合手机阅读

# 禁止事项
- 不要用"众所周知""随着...的发展"等陈词滥调开头
- 不要堆砌术语而不解释
- 不要写成产品广告
- 不要出现未经验证的数据

# 输出
直接输出完整文章（包含标题），不需要额外说明。
```

## 改动说明

| # | 原始问题 | 优化措施 | 应用技巧 | 预期效果 |
|---|---------|---------|---------|---------|
| 1 | 主题不明 | 指定具体选题 | Specificity | 文章有明确方向 |
| 2 | 无受众定义 | 详细描述目标读者画像 | Audience Setting | 语言风格适配读者 |
| 3 | 无风格锚定 | 定义语调+参考风格+具体要求 | Style Anchoring | 输出风格稳定一致 |
| 4 | 无内容框架 | 列出必须覆盖的 4 个要点 | Task Decomposition | 内容完整有逻辑 |
| 5 | 无质量红线 | 添加禁止事项清单 | Constraint Setting | 避免常见低质量模式 |
| 6 | 无格式规范 | 指定字数、结构、排版 | Structured Output | 适合公众号发布格式 |

## 测试建议

1. **字数测试** — 统计输出字数是否在 1500-2000 范围内
2. **结构检查** — 确认是否包含标题、引言、3-4 小节、结尾
3. **受众匹配** — 让一个非技术朋友阅读，看是否能理解
4. **金句检验** — 每个小节是否有可被引用的亮点句
5. **开头效果** — 前 3 行是否足够吸引人继续阅读
6. **禁忌检查** — 确认没有出现禁止列表中的问题
