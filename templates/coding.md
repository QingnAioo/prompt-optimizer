# 代码类任务优化模板

## 适用场景
代码编写、Bug 修复、代码审查、架构设计、算法实现

## 优化模板

```
# 角色
你是一位精通 [语言/框架] 的高级软件工程师，具有 [领域] 的丰富经验。

# 任务
[具体编码任务描述]

# 技术环境
- 语言/版本：[如 Python 3.11, TypeScript 5.x]
- 框架：[如 FastAPI, React 18]
- 依赖：[需要使用的库]
- 运行环境：[Node.js / Browser / Docker 等]

# 功能需求
1. [需求点 1]
2. [需求点 2]
3. [需求点 3]

# 约束条件
- 性能要求：[如 响应时间 < 100ms]
- 兼容性：[支持的环境/版本]
- 安全性：[需要考虑的安全问题]
- 代码风格：[遵循的规范，如 PEP8, ESLint]

# 输入输出示例
输入：[示例输入]
预期输出：[示例输出]

边界情况：
- [边界case 1] → [预期行为]
- [边界case 2] → [预期行为]

# 输出要求
1. 完整可运行的代码（包含所有 import）
2. 关键逻辑添加简要注释
3. 包含基本的错误处理
4. 提供使用示例

# 禁止事项
- 不要使用已废弃的 API
- 不要忽略错误处理
- 不要硬编码配置值
- 不要引入不必要的依赖
```

## Bug 修复变体

```
# 问题描述
[描述 bug 现象]

# 重现步骤
1. ...
2. ...
3. ...

# 预期行为
[应该发生什么]

# 实际行为
[实际发生了什么]

# 相关代码
[粘贴相关代码片段]

# 环境信息
[版本、OS、配置等]

# 要求
1. 找出根本原因（而非治标）
2. 提供修复代码
3. 解释为什么这样修复
4. 说明是否有潜在的副作用
```

## 关键优化点

1. **技术环境明确** — 避免生成不兼容的代码
2. **IO 示例** — 比文字描述更精确
3. **边界情况** — 提前考虑异常输入
4. **禁止事项** — 避免常见的代码质量问题
