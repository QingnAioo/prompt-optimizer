# 写作类任务优化模板

## 适用场景
文章撰写、邮件编写、文案创作、报告生成、翻译改写

## 优化模板

```
# 角色
你是一位 [领域] 的资深写作专家，写作风格 [风格特点]。

# 任务
撰写一篇关于 [主题] 的 [文体类型]。

# 目标受众
- 读者群体：[具体描述]
- 读者知识水平：[专业/中等/入门]
- 读者期望：[他们想从文中获得什么]

# 内容要求
- 核心观点：[1-3 个要传达的核心信息]
- 必须包含：[必须覆盖的关键点]
- 避免提及：[不应出现的内容]

# 风格与语调
- 语调：[正式/轻松/幽默/权威/温暖]
- 人称：[第一人称/第二人称/第三人称]
- 用语水平：[学术/商务/口语化]
- 参考风格：[可选 - 类似于谁的风格]

# 格式规范
- 总字数：[X] 字左右
- 结构：[要求的段落/章节结构]
- 标题要求：[是否需要标题/副标题]
- 特殊格式：[列表/引用/数据等]

# 质量标准
- 开头要求：[吸引注意力的方式]
- 逻辑要求：[论证结构]
- 结尾要求：[呼吁行动/总结/开放式]
- 原创性：不得直接复制已有内容

# 输出
直接输出成品文本，不需要额外解释。
```

## 关键优化点

1. **明确受众** — 决定了语言复杂度和表达方式
2. **风格锚定** — 比说"写得好"具体得多
3. **结构约束** — 避免输出过长或过短
4. **质量标准** — 给模型明确的评判尺度
