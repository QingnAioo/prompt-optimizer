# 提取类任务优化模板

## 适用场景
信息抽取、文本分类、实体识别、数据解析、摘要生成

## 优化模板

```
# 任务
从以下文本中提取 [目标信息类型]。

# 提取规则
- 提取字段：[字段列表及定义]
- 数据类型：[每个字段的类型约束]
- 缺失处理：如果文本中未提及某字段，填写 null
- 冲突处理：如果文本中有矛盾信息，取 [优先规则]

# 输出格式
严格按照以下 JSON 结构输出：

```json
{
  "field_1": {
    "value": "提取的值",
    "confidence": "high|medium|low",
    "source": "原文中的相关片段"
  },
  "field_2": {
    "value": null,
    "confidence": null,
    "source": null
  }
}
```

# 示例

输入文本：
"[示例文本]"

输出：
{
  "field_1": {"value": "...", "confidence": "high", "source": "..."},
  ...
}

# 注意事项
- 只提取文本中明确存在的信息，不要推断或补充
- value 保持原文用词，不做改写
- confidence 标注规则：
  - high: 原文明确陈述
  - medium: 需要简单推理
  - low: 基于上下文猜测
- 如果整段文本与目标信息无关，返回所有字段为 null

# 待处理文本
---
[用户输入的文本]
---
```

## 分类变体

```
# 任务
将以下文本分类到预定义类别中。

# 类别定义
- **类别A**：[详细定义 + 典型特征]
- **类别B**：[详细定义 + 典型特征]
- **类别C**：[详细定义 + 典型特征]

# 分类规则
- 每条文本只能属于一个类别（单标签）/ 可属于多个类别（多标签）
- 如果无法确定类别，标记为 "uncertain"
- 优先级：如果同时符合多个类别，优先选择 [规则]

# 输出格式
| 文本 | 类别 | 置信度 | 理由（一句话） |
|-----|------|--------|--------------|

# 示例
[2-3 个分类示例]

# 待分类文本
1. [文本1]
2. [文本2]
...
```

## 关键优化点

1. **字段精确定义** — 消除歧义
2. **缺失值处理** — 避免模型编造数据
3. **置信度标注** — 区分确定和不确定的提取
4. **来源标注** — 便于人工验证
5. **Few-shot 示例** — 对提取任务效果显著
