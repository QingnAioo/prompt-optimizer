# 创意类任务优化模板

## 适用场景
头脑风暴、创意生成、方案设计、命名/slogan、故事/剧本创作

## 优化模板

```
# 角色
你是一位 [领域] 的创意总监，擅长 [特长]，风格偏向 [风格倾向]。

# 创意任务
[任务描述]

# 背景约束
- 目标用户/场景：[谁在什么场景下使用]
- 品牌调性：[如果有品牌相关约束]
- 已有方案（需避免重复）：[列举已存在的类似方案]
- 必须包含的元素：[不可缺少的要素]
- 绝对避免：[红线/禁忌]

# 创意要求
- 数量：生成 [N] 个不同方向的创意
- 多样性：每个创意之间差异要大，覆盖不同风格/角度
- 创新度：[保守创新 / 中等突破 / 大胆颠覆]
- 可行性：[需要考虑落地可行性 / 纯创意不限制]

# 输出结构（每个创意）
## 创意 [N]：[一句话标题]
- **核心概念**：一句话描述
- **详细说明**：2-3 句展开
- **亮点**：为什么这个创意好
- **风险**：可能的问题或挑战
- **适用场景**：最适合在什么情况使用

# 评估维度
生成完所有创意后，用以下维度进行自评：

| 创意 | 新颖度(1-5) | 可行性(1-5) | 匹配度(1-5) | 综合推荐 |
|------|-----------|-----------|-----------|---------|

# 最终推荐
选出 Top 1 推荐方案，说明推荐理由。
```

## 头脑风暴变体

```
# 任务
针对 [问题/主题] 进行发散性头脑风暴。

# 思维框架
请从以下 6 个维度分别生成创意：

1. **替代** — 有什么可以替代现有方案？
2. **组合** — 可以将哪些元素组合？
3. **改造** — 如何改造/改良现有方案？
4. **放大/缩小** — 如果放大或缩小某个方面会怎样？
5. **挪用** — 其他领域的做法能否借鉴？
6. **逆向** — 如果完全反过来思考呢？

每个维度至少给出 2 个想法，共至少 12 个创意点。

# 输出
先列出所有创意，然后筛选出最有潜力的 3 个进行深入展开。
```

## 关键优化点

1. **约束激发创意** — 适度约束比完全自由更能产生好创意
2. **要求多样性** — 防止模型生成同质化结果
3. **自评机制** — 让模型筛选而非全部平铺
4. **思维框架** — 提供结构化的发散方向
5. **避免重复** — 明确告知已有方案
