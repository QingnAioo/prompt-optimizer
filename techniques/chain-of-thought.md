# Chain of Thought (CoT)

## 概述

Chain of Thought 通过引导模型逐步展示推理过程来提升复杂任务的准确率。

## 变体

### Zero-shot CoT
直接在 prompt 末尾加入触发词，无需示例。

**触发词选项：**
- "让我们一步步思考"
- "请展示你的推理过程"
- "先分析，再得出结论"

**模板：**
```
[任务描述]

请一步步思考，展示完整的推理过程，最后给出你的结论。
```

### Few-shot CoT
提供包含推理过程的示例。

**模板：**
```
[任务描述]

示例 1：
问题：[示例问题]
思考过程：
- 第一步：[分析]
- 第二步：[推导]
- 第三步：[验证]
结论：[答案]

现在请用同样的方式解答以下问题：
[实际问题]
```

### Auto-CoT
让模型自动生成中间推理步骤的分解。

**模板：**
```
[任务描述]

请先将这个问题分解为子问题，然后逐一解答，最后综合得出最终答案。

子问题分解：
1. ...
2. ...

逐步解答：
...

最终答案：
...
```

## 适用场景

- 数学和逻辑推理
- 多步骤决策
- 因果分析
- 比较和评估

## 注意事项

- 对简单任务（如简单分类）可能反而增加延迟而无收益
- 推理步骤过多可能导致模型"自说自话"偏离主题
- 建议结合 Self-Consistency 使用以提高可靠性
