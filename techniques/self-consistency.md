# Self-Consistency

## 概述

通过生成多条独立推理路径并取一致结论，显著提升复杂推理任务的准确率。

## 工作原理

1. 对同一问题生成 N 条不同的推理路径
2. 每条路径独立得出结论
3. 通过投票/一致性检查确定最终答案

## 模板

### 单次调用版（Prompt 内实现）
```
[任务描述]

请从三个不同角度分析这个问题，每个角度独立推理得出结论：

角度 1（[视角A]）：
推理：...
结论：...

角度 2（[视角B]）：
推理：...
结论：...

角度 3（[视角C]）：
推理：...
结论：...

综合判断：
如果多数角度得出相同结论，以该结论为准。如有分歧，分析分歧原因后给出最终答案。

最终答案：...
```

### 自我验证版
```
[任务描述]

请按以下流程作答：

1. 初始解答：给出你的第一反应答案
2. 质疑检查：假设答案是错的，找出可能的漏洞
3. 重新推理：基于质疑，重新独立推理一次
4. 最终确认：对比两次结果，确定最终答案

如果两次结果一致 → 直接输出
如果两次结果不同 → 进行第三次推理并取多数
```

### 多方案对比版
```
[任务描述]

请生成 3 个不同的解决方案，然后评估选择最优：

方案 A：[描述]
优点：...
缺点：...
适用条件：...

方案 B：[描述]
优点：...
缺点：...
适用条件：...

方案 C：[描述]
优点：...
缺点：...
适用条件：...

最优选择：基于 [评估标准] 选择方案 [X]
理由：...
```

## 适用场景

- 数学问题
- 逻辑推理
- 事实判断
- 高风险决策

## 注意事项

- 会增加 token 消耗
- 对简单任务没有必要
- 多路径需要真正独立（避免锚定效应）
